# KRMC — جامعه کوهنوردان کرمان

**KRMC** پلتفرم تخصصی جامعه کوهنوردی استان کرمان است؛ جایی برای پیدا کردن باشگاه، مربی، سرپرست، مقصد، اقامتگاه، پناهگاه و فروشگاه تجهیزات — با پروفایل عمومی، پنل نقش‌محور و زیرساخت آماده برای رشد محتوا و سئو.

هدف پروژه این است که اکوسیستم کوهنوردی کرمان را از حالت پراکنده خارج کند: کوهنورد بداند کجا برود و با چه کسی، باشگاه دیده شود، مربی و سرپرست معرفی شوند، و مسیرهای واقعی استان (از هزار و جوپار تا لاله‌زار) روی نقشه و در صفحات مقصد ثبت بمانند.

---

## چرا این پروژه؟

در کرمان جامعه کوهنوردی فعال است، اما اطلاعات معمولاً در کانال‌های پراکنده، گروه‌ها و صفحات شخصی می‌ماند. KRMC می‌خواهد:

- **کوهنورد** بتواند مقصد، باشگاه و راهنما را شفاف پیدا کند
- **باشگاه / مربی / سرپرست / فروشگاه** پروفایل عمومی و پنل مدیریت داشته باشد
- **محتوای برنامه‌ها و گزارش‌ها** برای دیده‌شدن در جستجو قابل رشد باشد
- تبلیغات و دیده‌شدن در آینده روی مدل شفاف‌تری بنا شود

## بخش‌های عمومی سایت

| بخش | مسیر | توضیح |
|-----|------|--------|
| خانه | `/` | معرفی پلتفرم، جستجو و دسترسی سریع به بخش‌ها |
| مقاصد | `/destinations` | قله‌ها و مسیرها با توضیح، ارتفاع و راهنماهای مرتبط |
| نقشه | `/map` | نمایش جغرافیایی مقاصد، باشگاه‌ها، اقامتگاه‌ها و … |
| باشگاه‌ها | `/clubs` | فهرست و صفحه عمومی هر باشگاه |
| مربیان / سرپرستان | `/coaches` | پروفایل تخصصی مربی و سرپرست برنامه |
| اقامتگاه‌ها | `/accommodations` | بوم‌گردی، هتل، مهمان‌سرا، کمپ |
| پناهگاه‌ها | `/shelters` | پناهگاه‌های کوهستانی (جدا از اقامتگاه تجاری) |
| فروشگاه‌ها | `/shops` | فروشگاه‌های تجهیزات کوهنوردی |
| پروفایل کاربر | `/u/{username}` | صفحه عمومی هر فرد یا مجموعه بر اساس یوزرنیم |

در داده‌های دمو، مقاصدی مثل **هزار، جوپار، لاله‌زار، پلوار، شاهوار، چال‌میجان، تفتان و شیرکوه** و چند باشگاه/فروشگاه نمونه از قبل seed شده‌اند.

## نقش‌ها و پنل‌ها

هر حساب یک **نقش** دارد و بعد از ورود به **پنل اختصاصی همان نقش** هدایت می‌شود. رابط پنل بر پایه استارترکیت Livewire لاراول (Fortify + Flux) ساخته شده است.

| نقش | پنل | کاربرد |
|-----|-----|--------|
| مدیر | `/panel/admin` | مدیریت کاربران، moderation نظرات، دید کلی سامانه |
| کوهنورد | `/panel/climber` | حساب شخصی و تنظیمات |
| باشگاه | `/panel/club` | مدیریت اطلاعات باشگاه تحت مالکیت |
| مربی | `/panel/coach` | ویرایش پروفایل تخصصی مربی |
| سرپرست | `/panel/leader` | ویرایش پروفایل تخصصی سرپرست |
| فروشگاه | `/panel/shop` | مدیریت اطلاعات فروشگاه |
| ارگان | `/panel/organization` | پنل نمایندگی ارگان‌ها |

همچنین:

- تنظیمات حساب: `/settings/profile` (نام، موبایل، یوزرنیم)
- امنیت (رمز عبور): `/settings/security`
- مدیریت نظرات (فقط ادمین): `/panel/admin/reviews`
- مدیریت کاربران (فقط ادمین): `/panel/admin/users`

در محیط local، از منوی سایدبار پنل می‌توان سریع بین اکانت‌های نقش‌های مختلف جابه‌جا شد تا تست نقش‌ها ساده باشد.

---

## هویت کاربری

- **شماره موبایل** شناسه یکتای ورود است (`09xxxxxxxxx`).
- **یوزرنیم** آدرس پروفایل عمومی است: `/u/{username}`.
- ورود فعلی با موبایل + رمز عبور انجام می‌شود؛ اتصال **OTP پیامکی** برای مرحله بعد در نظر گرفته شده است.

## اکانت‌های نمونه (دمو)

بعد از `php artisan migrate:fresh --seed` این حساب‌ها آماده تست هستند.

**رمز عبور همه اکانت‌ها:** `password`  
**صفحه ورود:** http://localhost:8000/login

| نقش | نام | موبایل | یوزرنیم | پنل | پروفایل عمومی |
|-----|-----|--------|---------|-----|----------------|
| مدیر | مدیر سامانه | `09120000001` | `admin` | `/panel/admin` | `/u/admin` |
| باشگاه | مدیر باشگاه نمونه | `09120000002` | `club-kerman` | `/panel/club` | `/u/club-kerman` |
| فروشگاه | مدیر فروشگاه نمونه | `09120000003` | `shop-kouhestan` | `/panel/shop` | `/u/shop-kouhestan` |
| ارگان | نماینده ارگان | `09120000004` | `organization` | `/panel/organization` | `/u/organization` |
| سرپرست | علی رضایی | `09120000005` | `ali-rezaei` | `/panel/leader` | `/u/ali-rezaei` |
| مربی | سارا محمدی | `09120000006` | `sara-mohammadi` | `/panel/coach` | `/u/sara-mohammadi` |
| سرپرست | حسین اکبری | `09120000007` | `hossein-akbari` | `/panel/leader` | `/u/hossein-akbari` |
| مربی | مریم حسینی | `09120000008` | `maryam-hosseini` | `/panel/coach` | `/u/maryam-hosseini` |
| کوهنورد | کوهنورد نمونه | `09120000010` | `climber` | `/panel/climber` | `/u/climber` |

پیشنهاد برای شروع بررسی:

1. با `admin` وارد شوید و بخش کاربران و نظرات را ببینید  
2. با `club-kerman` پنل باشگاه و ویرایش اطلاعات را تست کنید  
3. پروفایل عمومی مثل `/u/sara-mohammadi` یا `/u/climber` را باز کنید  
4. صفحات عمومی `/destinations`، `/map` و `/clubs` را بدون لاگین مرور کنید

## راه‌اندازی محیط توسعه

```bash
composer install
cp .env.example .env   # در صورت نبودن فایل محیط
php artisan key:generate
php artisan migrate:fresh --seed
npm install && npm run build
composer run dev
```

- سایت: http://localhost:8000  
- ورود: http://localhost:8000/login  

اجرای تست‌ها:

```bash
php artisan test --compact
```

## وضعیت فعلی و مسیر بعدی

الان لایه عمومی فهرست‌ها/نقشه، نقش‌ها و پنل‌ها، پروفایل عمومی بر اساس یوزرنیم، و مدیریت پایه کاربران/نظرات آماده است.

مسیر منطقی بعدی شامل ورود با OTP پیامکی، غنی‌سازی پنل هر نقش، و اتصال قوی‌تر محتوا (برنامه‌ها، گزارش‌ها، ثبت‌نام دوره) به پروفایل‌های عمومی خواهد بود.
